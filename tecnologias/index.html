    Tecnologias Utilizadas no MedFact

    O MedFact combina tecnologias modernas de desenvolvimento web, engenharia de dados, inteligência artificial e práticas de produção MLOps/DevOps.

    Detalhamento dos Componentes

    1. Python FastAPI

    Substituiu o antigo backend em Node.js para unificar todo o fluxo de Machine Learning em uma única pilha nativa. O FastAPI expõe a rota POST /api/verify, mantendo 100% de compatibilidade com o contrato que o frontend React já consome. Além disso, fornece documentação interativa automática via Swagger UI em /docs.

    2. PubMed Vector Store

    O MedFact implementa um banco vetorial customizado e persistente, projetado para operar com latência sub-milissegundo: - Cria vetores TF-IDF ponderados a partir do título do artigo, resumo (abstract) e termos de indexação MeSH. - Calcula a distância angular e similaridade de cosseno com a dúvida digitada pelo idoso. - Permite expansão contínua: toda busca inédita bem-sucedida no PubMed é automaticamente incorporada ao banco local.

    3. Groq API com Llama 3.1

    Utilizado para traduzir a linguagem fria e complexa dos periódicos científicos (ex: The Lancet, NEJM) em uma conversa tranquila e amiga para o idoso: - Temperatura controlada (0.3) para evitar alucinações. - Regra de ouro: nunca contradizer a evidência científica do PubMed recuperada pela Camada 2. - Caso o usuário não informe chave da Groq ou atinja o limite do plano, um motor de síntese didática heurística assume a resposta instantaneamente sem falhas.

    4. React 19 Frontend

    Desenvolvido com foco absoluto em usabilidade para a terceira idade: - Zero Frameworks Pesados: Apenas CSS moderno puro, garantindo carregamento instantâneo mesmo em conexões 3G/4G lentas. - Componentes Especializados: - AccessibilityBar: Permite ao idoso ajustar o tamanho da fonte e contraste visual com um único clique. - MascotPill: Mascote amigável em formato de pílula animada que acolhe o usuário e humaniza a experiência. - AboutModal: Janela informativa detalhando a origem acadêmica e o propósito social do MedFact.
